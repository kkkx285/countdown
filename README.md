# 我的倒计时

直接双击 `index.html`，用 Edge、Chrome 或其他现代浏览器打开即可。无需安装依赖、启动服务器或联网。

填写事件名称、目标日期和可选目标时间，点击“创建倒计时”。可以添加多个事件，点击卡片右上角的垃圾桶按钮删除。

- 按设备本地时间计算，目标时间支持秒；未填写时间以及旧版记录默认使用当天 00:00:00。
- 实时展示剩余天数和时、分、秒；每天按 24 小时拆分，不再采用自然日差。
- 每秒通过目标时间减去 Date.now() 重新计算，不累计每秒减 1 的误差。刷新或重新打开后按真实时间恢复；后台页面可能被浏览器暂停刷新，切回时立即校准。
- 目标到达后显示“时间到啦 🎉”，并显示“已过去”的天、时、分、秒，不出现负数。
- 保存目标日期和时间，不保存剩余秒数。沿用原 localStorage 键，旧记录自动兼容。
- 根据名称选择 emoji，支持中秋节、国庆节、生日、旅行、考试等，默认 ✨。
- 数据保存在当前浏览器的 localStorage 中，重新打开仍可读取。请使用同一浏览器和同一文件路径；移动文件、更换浏览器、清理网站数据或使用隐私模式可能导致无法保留或读取记录。存储不可用时页面会提示。
- 界面适配电脑和手机，支持键盘操作和减少动画偏好。

文件：`index.html`（页面结构）、`styles.css`（视觉样式）、`app.js`（计算、增删、本地存储）、`README.md`（使用说明）。
